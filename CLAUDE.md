# Puffins website — working agreement

- After making ANY change to files under `site/` (including small tweaks), commit and push to
  the `origin` remote (GitHub: `hemantpremgaatha/puffins`) on the `main` branch — do this
  automatically, without asking for confirmation first. The user has given standing
  authorization for this.
- Only stage/commit files actually related to the change (the `site/` files touched). Never
  blindly `git add -A` — this working directory also contains unrelated personal files
  (images, PDFs, scripts, an installer) that are untracked and must stay that way.
- Keep local `main` in sync with `origin/main` at all times — push right after each commit.
